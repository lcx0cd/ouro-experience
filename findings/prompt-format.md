# 提示词格式陷阱：为什么同样的内容，换个格式就退化

## 现象

同一个研究议题，两种 prompt 格式，输出天差地别：

**格式 A（"事实：……问题：……"）→ 退化：**
```
事实：Kiyosaki的$1.2B债务是1500套公寓组合债务，个人承担$3000-6000万，但数字是他在播客主动喊的。问题：他主动喊高债务数字，对商业利益有什么帮助？
→ "1. 增加 attention: 通过强调大型, 可能的, 可能的, 可能的, 可能的, 可能的..."
```

**格式 B（自然提问）→ 正常：**
```
Kiyosaki的$1.2B债务是他与合伙人共同持有的1500套公寓的债务，个人实际承担$3000-6000万，但数字是他在播客主动喊的。他主动喊高债务数字，对他的商业利益有什么帮助？
→ "Kiyosaki主动喊高债务数字的商业利益可能包括以下几点：1. 吸引关..."
```

## 系统对照（同模型，同内容，仅改格式）

| Prompt 格式 | steps | 输出 | 状态 |
|---|---|---|---|
| "事实：…问题：…" | 2 | "增加 attention: 通过强调大型, 可能的, 可能的…" | ❌ 退化 |
| "事实：…问题：…" | 4 | "帮助增加品牌形象：Kiyosaki主动喊…" | ⚠️ 略好但不完整 |
| 自然提问 | 2 | "这里的关键是'主动喊'，也就是他在声明的时候, 他是否有意识…" | ✅ 正常 |
| 自然提问 | 4 | "Kiyosaki主动喊高债务数字的商业利益可能包括以下几点：1. 吸引关…" | ✅ 正常 |

## 根因假说

Ouro-1.4B base 的训练语料中，"事实：…问题：…"这类结构化格式大概率对应**多选题/判断题**（训练数据中常见格式）。模型看到这个前缀就触发了训练中见过的硬编码输出模式（列选项、重复、数字爆炸），而不是真正理解并回答。

类似地，"A. B. C. D."选项列表格式（Q8）也会让模型进入"单选题模式"，把问题当选项处理，输出"只有一个高-low-low-low (HLLL) 结构"这种无意义内容。

## 教训

1. **用小模型时，prompt 必须用自然语言完整叙述**，不要用结构化标签（`事实：`、`问题：`、`A.`、`B.`）。
2. 大模型（如 DeepSeek）对格式免疫——它理解"事实：问题："只是文本结构。**格式敏感度本身就是小模型和大模型差距的一个可量化信号**。
3. 评测小模型前，先用 2-3 个 prompt 变体做 sanity check，确认没有触发格式陷阱，否则整个评测无效。

## 怎么判断模型是否进入了"格式陷阱"

看输出开头：
- ❌ 输出以编号/选项开头（`1.`、`A.`、`a) 美国的'美国'高贷`）且内容循环 → 陷阱
- ✅ 输出是连贯的自然语言推理（`这里的关键是…`、`首先，我们需要理解…`）→ 正常
